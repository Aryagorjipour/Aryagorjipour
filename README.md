### What I'm building

🔍 **[logdive](https://github.com/Aryagorjipour/logdive)** — A single-binary log query engine in Rust. `jq` with memory, time ranges, and filters. SQLite-backed index, no infrastructure, no YAML, no daemon. Try it: `cargo install logdive`.

🎓 **Amoosha** — Multi-tenant LMS platform in Go, EU-first. Currently in active development.

🛠️ **Smaller Go tools** — [smartgosms](https://github.com/Aryagorjipour/smartgosms) (multi-provider SMS library), SPWD (CLI password manager), SFD (concurrent downloader).
